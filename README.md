# Sunday Roast website

Static HTML/CSS/JS site prepared for GitHub Pages.

## Publish
1. Create a public GitHub repository.
2. Upload all files and folders in this package to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Add `www.sundayroast.studio` under Custom domain.
5. At the domain registrar/DNS provider, point `www` to your GitHub Pages address as instructed by GitHub.
6. Turn on Enforce HTTPS when available.

The site is deliberately dependency-light: no build system is required.
